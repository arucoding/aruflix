## ❓ Sering ditanya

**Kok play pertama agak lama?**
Servernya kadang "tidur" kalau lama nggak dipakai. Tunggu beberapa detik, atau tekan **Coba lagi**.

**Subtitle-nya bisa diatur?**
Subtitle Indonesia nyala otomatis dan ukurannya udah diatur senyaman mungkin. Nggak ada pengaturan tambahan — biar simpel.

**Aman nggak?**
Aplikasi ini nggak minta data pribadi apa-apa. Nggak ada akun, nggak ada iklan.
